# 组件使用规则

当前没有可调用的组件库。下面的规则在第一批组件被验收之后才生效。

- 设计新页面前先读 `03-Components/component-index.json`。
- 索引里没有的节点 ID 和组件 Key 不能当作已经存在。
- 优先使用索引中的实例，不重复绘制同功能组件。
- 颜色、字号、间距只使用确认状态为已确认的 token。
- 未确认的 Recommended 值不能写进 Figma 变量后当成正式规范。
- 不替换原文件里的导航图标和银行标志。
- 组件缺失时，先看现有 Variants 和 Properties 能否覆盖。
- 确实要新增时，先写明原因，再更新索引。索引中的 ID 必须来自创建结果。
