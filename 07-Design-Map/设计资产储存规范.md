# 设计资产储存规范

日期：2026-11-25

这份规范规定以后往地图里放什么、放在哪、怎么命名。页面目录已经建立。启动、登录注册、首页的素材和控件已按本规范复核过一部分。模块清单和界面截图从这些已复核的业务开始，不回头重扫未展开的区域。

## 通用字段

每项资产都要有：唯一 ID、名称、类型、所属业务、所属页面、父级资产 ID、Figma 文件 Key、节点 ID、原始节点名、原始节点类型、来源链接、本地路径、处理状态、产品确认状态、最近更新时间、备注。

没有本地文件时，路径留空，不要编一个路径。普通 Frame 没有 Component Key，字段留空。

确认状态沿用现有约定：未确认就是 `unconfirmed`。不要把建议值写成已确认。

## 处理状态

节点读取、资产识别、预览获取、提取、入库、关联、产品验收，各自单独记。取值只允许：未处理、部分完成、已完成、处理失败、不适用、待确认。

读完节点不等于提取完成。提取完成不等于已入库。入库不等于产品已验收。

## 素材和组件

素材是一张可以单独拿去用的图。图标、字标、插画、背景图都属于素材。它自己没有输入、选择或点击结构。素材继续进 `01-Icons`、`02-Images` 和 `asset-index.json`。同一图形只留一份文件，其余节点写 `duplicate_sources`。字节不同、又没有核对过路径的图形，不写 `duplicate_sources`。

扫一页时，除了下面的控件，还要拆出这些素材：固定字标、入口图标、凸起底栏按钮上的图标。字标即使是文字节点，只要是固定的标志文字，就导出一份。一排「图标 + 短标签」整排不是按钮，但每个图标仍是素材。订单卡片和横幅不整组导出。里面的图标、图片填充、名叫 icon_ 的组、金币或数字徽章、进度条要拆出来。只读到档位或标题文字，不算这些图已经采集。

组件记录这些有结构的界面单位：按钮、输入框、下拉选择器、复选框、弹框外壳、进度条。它记录结构、从节点读到的样式、状态，以及它用到的素材 ID。组件不因为长得像一张图就导出成 PNG 或 SVG。

Figma 里真实读到的 `COMPONENT`、`COMPONENT_SET` 才有 Key、变体和属性。普通 Frame 或 Group，只要结构符合上面的单位，记成候选项，Key 留空，标准化保持未完成。没有读到的状态写成「未读到」，不要补悬停或禁用。

弹框外壳记录宽高、圆角、底色、标题条的渐变停点、标题字、内边距，以及内部按钮候选项 ID 和图片素材 ID。弹框里的插画组、图标也要导出，ID 写进这条记录。外壳和按钮已经记下、插画 ID 仍空着，这一条不能结案。不把整个弹框压成一张图。

进度条把底槽和色条分开记颜色、圆角和宽高。同一结构在不同状态上的颜色写在实例上。只记这一帧读到的色条宽度，没有第二帧就不写动画。

纯色或渐变铺在界面上时，记到该界面或设计属性，不另存成一张背景图。这句话只约束底板。由矢量、文字和标志拼成的插画，没有图片填充也要导出。节点里真有图片填充时，优先存原图。原图过大、无法整份写入时，存节点的 1 倍 PNG，不放大，并在备注里写下原图哈希和字节数。文件太大不是跳过的理由。

一个控件里的图标仍然是素材。下拉框引用箭头图标，复选框引用对勾图标，组件记录只写素材 ID，不把图标再存一份。结构里写了图标时，素材 ID 不能空着，也不能以「未另存」结案。旁边尺寸和底色相同的按钮，图标仍要各自导出或核对。已经入库的导航图标不重复导出。底栏中间的凸起按钮如果不是那些图标的实例，单独记按钮和它的图标。页面里没有节点的系统横条不补造。

组件不按业务页面拆成多套。页面、界面和节点记在实例上，资产库可以按这些位置筛选。某一页读到的样式和别的实例不同，把差异写在该实例上。结构和读到的样式都不同，才另建候选项。金币、字标、插画组不是控件。已经记成候选项的保留原记录，标成不是控件，组件入口不再展示。

## 扫界面时怎样判断一张图要不要入库

按节点判断，不按截图上的红框整块入库。

这些要入库：

- 控件内部的图标。按钮、下拉箭头、复选框对勾各自对应一个素材 ID。
- 弹框内部的插画和图标。弹框记录写这些 ID，不把弹框压成一张图。
- 横幅、奖励条、卡片标题旁边的小图标。图片填充、名叫 icon_ 的组、独立的矢量徽章都拆出来。整组横幅不导出。
- 由卡片、箭头、标志、固定文字拼成的说明插画。没有图片填充也要导出。
- 原图过大时仍要落节点的 1 倍 PNG，备注写原图哈希和字节数。

这些不入库：

- 纯色或渐变底板、空白矩形。颜色记在界面或模块上。底板上的徽章仍然入库。
- 名字或用途相近的旧文件。没有和当前节点对上字节或路径之前，不算已经采集。

卖出复核漏掉的，就是这几条没有做完。收款信息和联系客服只记了按钮，图标留成「未另存」。提示弹框记了外壳和按钮，里面的 UPI 卡片没有导出。卖出奖励只读了档位文字，红包图和金币徽章没有拆。奖励卡标题旁的提示图标不在按钮、输入框、下拉、复选框里，就被放过。银行卡转到 UPI 的插画被当成已经入库的 UPI 字标。须知卡片上的渐变底板和空白矩形本身不入库。警告三角此前已经入库，不重复导出。

新的 390 宽客户端界面，没有对应节点时，用 `04-Design-Tokens` 里的推荐值。已经读到节点的界面，以节点上的样式为准。推荐值的确认状态保持 `unconfirmed`。

资产库页面分三个入口。组件入口按对照路径展示：页面、节点 ID、Figma 链接、Key、结构、读到的样式、状态、引用的素材 ID。按钮、输入框、下拉、复选框还没有节点时，留在「尚未采集」，出稿时不要自己补一套样式。标成不是控件的记录不出现在组件入口。

## 各类资产放什么

页面：完整截图、尺寸、状态及关联页面、布局、模块清单、用到的组件和素材、用到的规范、扫描进度。截图还没有时，记「待获取」，不因此停掉页面目录，也不因此停掉已经完成的素材和控件复核。

截图只导出 `kind` 为界面或弹窗的节点，1 倍 PNG，不放大。整理板和组件母版不导出。文件放在 `05-Screenshots/<页面名>/<界面 ID>.png`。地图里该界面的 `screenshot` 写成这个路径。截图是界面预览，不进 `asset-index.json`。

模块是界面里的一块结构，不是一张图。标题栏、入口图标排、资产区、订单列表、常见问题、底栏、弹框内容，各记一条。记录放进 `ui-design-map.json` 的 `modules`。一条模块要有：模块 ID、名称、所属界面 ID、节点 ID、宽高、布局方向、间距、内边距、已经入库的组件 ID、已经入库的素材 ID。预览图可以先空着。节点已经读过的，模块可以先于截图写成部分完成。订单卡片是模块，里面的倒计时条继续引用已有的进度条候选项。

模块：预览、尺寸、布局方向、间距和 Padding、Auto Layout、背景和样式、子组件、关联页面。

组件：预览、真实节点类型、结构、宽高、尺寸规则、颜色字体间距圆角边框阴影、已有的 Key / 变体 / 属性、依赖的素材和规范、被哪些页面用、标准化状态、实例复用是否验证过。Frame 或 Group 只记候选项。

视觉素材：继续放在 `01-Icons` 和 `02-Images`。索引继续用 `asset-index.json`。要有文件、原始尺寸和颜色、格式、分类、状态、Hash、来源节点、引用关系、重复关系和批次。已有批次不改写。新入库用新批次。

设计属性：继续用 `04-Design-Tokens` 里的 8 个文件。不另起一套规范。字段包括类型、名称、原稿值、推荐值、已确认值、来源节点、场景、关联对象、确认状态。

## 路径和命名

| 类型 | 路径 | 命名 |
| --- | --- | --- |
| 地图数据 | `07-Design-Map/ui-design-map.json` | 业务 `biz-`，界面 `scr-`，组件 `cmp-` |
| 地图说明 | `07-Design-Map/UI设计资产地图.md` | 由 JSON 生成，不手写第二套数字 |
| 核查表 | `07-Design-Map/UI设计资产核查清单.xlsx` | 工作表名固定 |
| 进度 | `07-Design-Map/scan-progress.json` | 按页面记断点 |
| 待办 | `07-Design-Map/pending-tasks.json` | 任务 ID `T-` |
| 图标 | `01-Icons/<分类>/` | 沿用现有英文短名 |
| 图片 | `02-Images/<分类>/` | 沿用现有英文短名 |
| 规范 | `04-Design-Tokens/*.json` | 不新建平行文件 |
| 组件索引 | `03-Components/component-index.json` | 只记真实读到的组件 |
| 界面截图 | `05-Screenshots/<页面名>/` | 文件名用界面 ID，如 `scr-0008.png` |
| 资产库页面 | `asset-preview.html` | 素材、组件、设计规范三个入口 |

## 更新机制

改地图时先改 `ui-design-map.json`，再生成 Markdown 和 Excel。素材正文仍以 `asset-index.json` 为准，地图只存资产 ID。历史批次、旧路径和已删除来源的记录不覆盖、不删除。变更写进当天的 `session-changelog`。

每个已复核的业务，先写模块清单，再补该业务的界面截图。素材和控件已经按本规范结案的页面不再整页重扫。截图复核点名了缺的节点时，只补这些节点。教程引导里未展开的区域、彩票、换肤、1.5 走查不进入这一步，除非当前业务已经走到那里。
